### 📁 Key Projects

#### 1. 딥러닝 활영 CT 없이 단독 PET의 정량화 및 템플릿 제작
* **핵심 기능**
- PET 단독 분석 프레임워크: 3D U-Net 구조를 활용하여 CT나 MRI 없이 PET 영상만으로 정밀한 뇌 세그멘테이션 및 SUV 정량화 구현 

- 하이브리드 데이터 전략: 수백 건의 제한된 의료 데이터셋 한계를 극복하기 위해 평균화 템플릿 제작 및 Rigid/Affine 정합(Registration) 기술 적용 

- 데이터 파이프라인 구축: DICOM 데이터를 NIfTI 포맷으로 변환하고 정규화, 크롭 등 학습을 위한 전처리 및 3D 시각화 모듈 개발
* **성과**
- 분석 성능 개선: 템플릿 보완 전략을 통해 Dice Score 0.79 달성 (기존 연구 0.67 대비 약 12% 성능 향상) 

- 정밀 진단 가능성 확인: SUV 정량화 오차를 4.7% 이내로 최소화하여 단독 PET 진단의 임상적 활용 가치 입증 

- 의료 접근성 향상: MRI 촬영 불가 환자(심장박동기 보유자 등)를 위한 대안을 제시하고, 약 13시간 이상 소요되는 기존 진단 프로세스의 시간과 비용 절감 기여

* **기술 스택**: Python, PyTorch, 3D U-Net, SimpleITK, NumPy, Pandas, Matplotlib
#### 2. 피부암 진단 보조 및 환자 추적 관찰 서비스 (NIPA 최우수상)
* **핵심 기능**: CNN-ViT 하이브리드 모델을 통한 높은 진단 정확도 확보 및 웹/앱 연동
* **성과**: 복합 모델링을 통해 기존 단일 모델 대비 성능 개선

#### 3. SNS 데이터 기반 디저트 트렌드 분석 (이스트소프트 최우수상)
* **핵심 기능**: 구글 Trends 및 SNS 크롤링 데이터 전처리 및 키워드 자동 분석
